01 · My contribution

I designed, developed, checked, and launched this website independently. I translated the company’s services and production identity into a clear browsing and contact experience.

02 · Purpose & personal contribution

Potential clients needed to understand the production services, see the company’s identity, and make a project inquiry. I owned the structure, visual design, frontend development, and deployment.

03 · Frontend & interaction work

  • Service, process, pricing, and contact sections with responsive navigation.
  • JavaScript interaction and animation behavior with reduced-motion detection.
  • A contact form handler that checks validity, disables duplicate submission, and surfaces success or failure; direct email options provide another contact path.
  • A Three.js camera interaction loaded for the final call to action.
  • Vite build configuration with a GitHub Pages base path.

04 · Challenge: visual media on mobile

The repository’s latest recorded change improves mobile hero performance. The site balances a media-led presentation with responsive layouts and user preferences for reduced motion.

The served site is a static HTML/CSS/JavaScript entry built through Vite. React packages and alternate React components also exist in the repository; they are not evidence that the current live entry is a React application. Keeping that distinction avoids overstating the architecture.

05 · Checks, launch & outcomes

The existing case study records end-to-end checking and launch; the GitHub Pages site was reachable during this review. A specific automated test suite is not documented. The current JavaScript implements Web3Forms handling, but this review did not submit a real inquiry to verify delivery.

The prior portfolio reports 40–80 monthly visits and positive feedback on navigation. These are reported results without a current analytics export. The site is responsive web, not a native mobile app.
